## 💳 Metode Pembayaran

Platform mendukung multiple payment methods untuk kemudahan pelanggan:

### 🔷 **QRIS** (Quick Response Code Indonesia)

- Pembayaran instan dengan scan QR code
- Support semua bank dan e-wallet

### 🏦 **Transfer Bank**

- Transfer ke rekening perusahaan
- Verifikasi pembayaran otomatis

### 🚀 **E-Wallet**

- GoPay, OVO, Dana, dan e-wallet lainnya
- Pembayaran instan tanpa konfirmasi

### ✅ Semua pembayaran terintegrasi dengan sistem otomatis untuk update order status
